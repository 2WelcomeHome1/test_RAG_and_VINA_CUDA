# RAG и Vina-CUDA

Репозиторий содержит решения трёх задач. Каждое решение размещено в отдельной ветке; `main` служит для навигации.

| Ветка | Задача и результат | Отчёт и запуск |
|---|---|---|
| [task-1](https://github.com/2WelcomeHome1/test_RAG_and_VINA_CUDA/tree/task-1) | **RAG API.** Загрузка документов, хранение оригиналов в MinIO, чанков и векторов — в PostgreSQL/pgvector, ответы с цитатами. Доработаны исходная заготовка, обработка ошибок и устойчивость; добавлены приёмочные тесты и мутационная проверка. Для воспроизводимости используются детерминированные провайдеры без внешних AI API. | [REPORT.md](https://github.com/2WelcomeHome1/test_RAG_and_VINA_CUDA/blob/task-1/REPORT.md) |
| [task-2](https://github.com/2WelcomeHome1/test_RAG_and_VINA_CUDA/tree/task-2) | **Поиск источника недетерминизма в Vina-CUDA 1.1.** Найдено чтение неинициализированного хвоста shared memory, подготовлены исправление и CUDA-тест «до/после». Сохранены результаты изолированной проверки на H100; естественный разброс повторных запусков полного приложения не проверялся. | [REPORT.md](https://github.com/2WelcomeHome1/test_RAG_and_VINA_CUDA/blob/task-2/Vina-CUDA/REPORT.md) |
| [task-3](https://github.com/2WelcomeHome1/test_RAG_and_VINA_CUDA/tree/task-3) | **Развитие RAG API из первой задачи.** Подключены модели эмбеддингов, реранкер и генерация через Ollama. Добавлены конфигурация запуска на GPU, обработка сбоев моделей и логирование; расширены тесты и мутационная проверка. | [REPORT.md](https://github.com/2WelcomeHome1/test_RAG_and_VINA_CUDA/blob/task-3/REPORT.md) |

Краткий отчёт о работе, команды и параметры запуска, требования к среде и ограничения проверки приведены в `REPORT.md` соответствующей ветки. Для `task-2` отчёт находится в папке `Vina-CUDA/`.

Исходный код и файлы запуска находятся в соотвествующих ветках.
